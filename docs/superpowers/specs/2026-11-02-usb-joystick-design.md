# USB 两轴摇杆实时监视

用户已确认采用本地单文件网页和 Gamepad API 方案。

页面显示连接状态、设备名称、X/Y 轴实时百分比及二维位置。默认读取轴 0、1，允许选择其他轴和设备。使用 requestAnimationFrame 每帧重新获取设备数据，拔出后清空读数。未连接、轴不足、不支持 API、不安全上下文和访问被阻止均给出提示。

用户补充的校准要求：原始 X 范围 [-0.7752, +0.9081]、原始 Y 范围 [-0.9062, +0.8025]。按最新要求使用原始半径 0.002（含边界）的圆形死区。每个象限按对应 X/Y 上限形成校准椭圆，将当前原始方向上从死区边缘至椭圆边界的半径线性映射到输出半径 0～1，输出方向为按行程缩放后的向量方向；超出边界截断到单位圆周。斜向校准分量同为 100% 时输出分量各约 70.7%，不再分别对每轴做死区和截断。归一化后在页面 Y 向下坐标中视觉左旋 90°（显示 X = 原始 Y，显示 Y = -原始 X）。数值保留一位小数，图形与进度条使用未舍入结果，反向选项作用于显示轴。

只使用原生 HTML、CSS、JavaScript，无依赖和构建步骤。通过 localhost 打开。此版本不解析厂家私有 HID 或串口协议，不声称读取 ADC 原始值。用 Node 内置断言和最小 DOM 模拟检查数据到界面的行为；真实设备需要用户插入验证。
